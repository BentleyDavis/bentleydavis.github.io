# Supplement Tracker — Sample Code

Reference code copied from the Muse artifact `supplement-tracker`. This
is NOT a live app on this site.

It is a fullstack TypeScript/Bun app (`client/` + `server/` + `drizzle/`
schema). It needs Muse's server runtime and its SQLite database to run,
and it will not run as static files on Netlify.

The live data was NOT copied. A final data sync into Firestore is pending
once the new apps exist. See `AGENTS.md` in the parent folder for the
app's rules and the plan for its replacement.
